### [BLOCKER] One gym_domain row with app='client' is the whole cutover — hostname must be exact-lowercase, no www stripping exists anywhere

- **Verdict:** `UNVERIFIED`
- **Executor:** `migration` · **Confidence:** `read-the-code`
- **Where:** packages/data/src/server/resolve-tenant.ts:193 + :137-140; supabase/functions-canonical/gym_id_por_host.sql; apps/client/src/proxy.ts:101
- **Evidence:** resolve-tenant.ts:193 is the ONLY normalization: `const hostname = host?.split(":")[0].toLowerCase() ?? "";` — port stripped, lowercased, and that is all. No `www.` strip, no trailing-dot strip, no punycode. It is then passed verbatim to the RPC (:137-140 `client.rpc("gym_id_por_host", { p_hostname: hostname, p_app: app ?? null })`), whose live body (verified against prod pg_proc, byte-identical to supabase/functions-canonical/gym_id_por_host.sql, single overload, no drift) is `where d.hostname = p_hostname and (p_app is null or d.app = p_app)` — plain `=`, no `lower()` on the column. apps/client/src/proxy.ts:101 declares `"client"`, so p_app='client' and an app='admin' row for the same hostname would NOT match.
- **Impact:** Without the row, gym_id_por_host returns null → resolveHostUncached returns {matched:false,tenant:null} → resolveTenant returns null → tenantHeaders (resolve-tenant.ts:270-280) DELETES x-gym and x-brand. redfunctionaltraining.com serves the base brand with an empty catalog forever. With the hostname stored non-lowercase (e.g. 'RedFunctionalTraining.com') the `=` never matches and the symptom is identical and silent.
- **Change:** Migration (apply via MCP apply_migration against live — never `supabase db push`, per the version-drift rule; commit the identical file under supabase/migrations/):

insert into public.gym_domain (gym_id, hostname, app, created_at)
select g.id, 'redfunctionaltraining.com', 'client', timestamptz '2026-07-09 07:00:00+00'
from public.gym g where g.slug = 'red'
on conflict (hostname) do nothing;

The backdated created_at is load-bearing — see the oldest-wins finding. Hostname MUST be lowercase, no scheme, no trailing slash, no port.
