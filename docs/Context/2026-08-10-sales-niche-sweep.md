# Sales niche sweep — beyond the 12-genre taxonomy

**Date:** 2026-08-10
**Product:** iBookit (`ibooki.lat`)
**Inputs:** `docs/brand/PRODUCT-BRIEF.md` §2 (12 genres + 5 traps) and `docs/Context/2026-08-08-membership-booking-market-taxonomy.md` (sourcing + fit method).
**Method:** 17 MX-targeted web searches against the same fit rule as the source taxonomy — recurring paquete/plan with vigencia, sold against a scheduled session with a named roster, attendance taken. Same verdict scale (STRONG/PARTIAL/POOR) and the same four gaps (GAP-A per-practitioner appointment book · GAP-B resource-inventory booking · GAP-C guardian↔minor model · GAP-D cohort/term enrollment). This file only adds niches **absent** from the 12 genres or their named sub-niche lists; it does not re-litigate anything already verdicted there.

## 4. Private-lessons adjudication (piano, tutoring, and the capacity-1 question)

The brief's declared trap is **"a 1:1 book on a named practitioner"** (doctors, dentists, physio, salons, vets) = POOR/GAP-A. The owner's question: does a recurring *private* class — same subject, same student, every week — collapse into that trap, or does it survive as a capacity-1 class?

**The mechanical test that separates them, found consistently across the evidence:**

| | GAP-A trap (POOR) | Capacity-1 class (PARTIAL) |
|---|---|---|
| Scheduling | Client re-books a slot **per visit**, availability-dependent, often first-available practitioner | Student is assigned **one fixed weekly day/time with one teacher**, standing, until cancelled |
| Billing | Per-session or punch-card fee-for-service | Monthly **mensualidad**, same as any plan |
| Evidence (MX) | Superprof, TusClases, Preply, AmazingTalker — marketplace copy explicitly sells "horario flexible para organizar tus clases cuando quieras" ([amazingtalker.com.mx](https://www.amazingtalker.com.mx/tutor-price/english)) | Musicando: insc. $1,700 + mensualidad $2,500 ([musicando.com.mx](https://www.musicando.com.mx/clases-piano.php)); Academia Musical Rubinstein: $1,800/mes (1 hr/sem) or $950/mes (30 min/sem), insc. anual $1,600, con recitales ([academiamusicalrubinstein.com](http://www.academiamusicalrubinstein.com/)); Academia Pianissimo: individual con muestra pública ([academiapianissimocdmx.com](https://academiapianissimocdmx.com/)) |
| Why it differs mechanically | Every visit re-triggers GAP-A's variable-slot problem — there is no standing "session" to attend | A standing weekly slot **is** a repeating session in Agenda with roster size 1 — no per-visit scheduling problem exists at all |

**Verdict: PARTIAL, conditional on the operator's actual booking discipline — not on the subject matter.** The same "piano lesson" search returns roughly half fixed-slot music schools (PARTIAL, sell it) and half flexible marketplace tutors (POOR, walk away). This also governs the private tiers already named PARTIAL/GAP-A in the source report (private language conversation, GYROTONIC/StretchLab-style assisted stretching) and the new regularización and improv rows above — **it is one general rule, applied five times, not five separate findings.**

**One-question screen for sales:** *"¿el mismo horario cada semana con el mismo maestro, o agendan cada clase por separado?"* Fixed slot → sell it like any class. Rebooked per visit → it's the appointment-book trap regardless of what the business calls itself.

**What still doesn't fully clear to STRONG even when it passes:** no per-teacher payroll/hour allocation, no make-up-class credit tracking — cosmetic gaps, not blocking ones, same footnote the source report gave G3's private tier.

## Summary of what this sweep adds

- **8 new STRONG niches**, **7 new PARTIAL niches**, **4 POOR/trap confirmations** beyond the 12-genre taxonomy.
- The single most sales-actionable addition: **circo and parkour price by weekly frequency exactly like G1 combat sports** — zero new pitch to write, just new search terms.
- The single most important adjudication: **private lessons (piano, tutoring, language, stretching) split on booking discipline, not subject** — fixed weekly slot with the same teacher survives as a capacity-1 class; marketplace-style rebooking is the same GAP-A trap as a dental office, regardless of vertical.
- Two new named gaps beyond the source report's GAP-A/B/C/D: **GAP-E (no B2B/company-invoice billing)** for corporate wellness, and a **care-record variant of GAP-C** for medicalized senior day centers.
