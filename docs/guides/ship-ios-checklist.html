Settle these three first — each can re-price the whole plan, none needs an Apple account

  1. Hermes Intl.DateTimeFormat with timeZone:'America/Mexico_City' + formatToParts on a real Android device. An hour reading 18 = UTC leaked (fail); 12 = pass. → step 1.2b
  2. Metro resolves @gym/domain/rules — raw .ts, subpath exports, pnpm isolated linker, no build step. A red kills the share-the-pure-packages premise. → step 1.2b
  3. Does Apple issue a CFDI for a third-party IAP subscription in Mexico? Buy any third-party sub on a Mexican Apple ID with your RFC set, watch for the EDICOM email. One hour. Decides all of Stage 3.

Read this before you promise anyone a date

  • Stage 1 ships a shell, not the app. Stage 1.5 is the app: 44–60 solo-dev days, of which 15–20 is foundation before the first sector screen exists.
  • Stage 2A's "3–7 days" is a compliance punch list run against a finished app — none of it can be done first. That clock starts after Stage 1.5.
  • The binary you submit must already contain 2A.1, 2A.4 and 2A.6. None of them can be added by a form or an OTA update.
  • Stage 3 is optional and the ruling is: don't. Ship free + web billing (Stage 3-alt). Adding IAP spends Guideline 3.1.3(f) permanently.
